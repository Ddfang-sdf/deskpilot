# DeskPilot 本地大规模手工测试计划(v1.1)

| 项 | 内容 |
|----|------|
| 版本 | v1.1(2026-09-08,sdfang 评审追问后补全:用例 72→87,补 9 处覆盖缺口;v1 总数 79 系笔误,实测 72) |
| 对象 | deskpilot 当前构建(v0.3.5+REQ-001/002+ISS-0041/0042,共 29 工具) |
| 形态 | **AI 驱动调用 + 人类裁判**:AI 经 MCP/HTTP 发起全部调用并自验可自动判据;人类负责审批类操作、视觉确认与不可自动判据项 |
| 原则 | 不碰用户数据、不装新软件、不推送任何内容;每条用例可逆,现场可恢复 |

## 1. 目标与范围

**测**:29 个工具全量 + 四道闸 + 审批/入白/撤回/墓碑 + 急停双通道 +
安全网四重 + 感知自愈 + daemon 恢复 + 错误 AI 友好面。
**不测**:性能压测、多显示器(本机单屏)、客户端矩阵(仅当前 Claude Code)、
网络异常注入(另行)。

## 4. 执行方式

- **角色**:AI 按批次顺序逐条发起调用并填「自动判据」列;人类处理
  审批/确认弹窗,并对「人」列判据打 ✓/✗/备注。
- **节奏**:每批结束暂停,出一次小结(过/败/疑似),人类确认再开下一批;
  B-16(31s 等待)与 C-04(90s 等待)排在批次末尾。
- **审批配合点**:C-02/C-03/C-04、D-03/04/05/08/09、D-14/15、B-18——
  到点前 AI 显式提示,人类在 90s 内操作。
- **禁线**:全程不碰用户自有文档/数据;测试文件一律落 shell 展开后的 `$env:TEMP`/`%TEMP%`(见 P-04 注);
  不推送任何内容;不动白名单出厂文件(只动 policy.local.yml,且 P-04 已备份)。

## 5. 记录方式

- **记录表**(本文件执行副本):每用例行 = 编号|结果(过/败/疑似/跳过)|
  实测值|证据(审计行号/截图路径)|备注。
- **证据链**:审计 JSONL 基线后增量为系统侧证据;「人」列判据由人类在
  记录表直写;截图统一落 audit/shots(受管清理不删当天)。
- **失败处理**:失败用例当场复跑一次仍败→停批次,按规则提单
  (修改引入必带【修改引入】前缀并先认账);疑似项记入「待查清单」
  不当场展开,收尾统一评审。
- **收尾报告**:通过率/失败单号/待查清单/现场恢复确认(P-04/06/08 还原)。

## 6. 现场恢复(全部用例执行后)

1. 关闭全部测试窗口(差分核对,不动用户原窗);
2. 桌面图标按 P-08 快照对照,位移者拖回;
3. `policy.local.yml` 按 P-04 备份还原(入白/墓碑类痕迹清除);
4. 剪贴板按 P-06 还原;测试文件按 shell 展开后的 `$env:TEMP`/`%TEMP%` 清理(**勿写字面量**);
5. 审计日志保留(受管目录,无需清理)。

## 7. 通过标准

- P0(批次 B/C/D 全列)100% 通过;
- 全量 87 例通过率 ≥95%,且无一类错误(安全面误判)出现;
- 观感面(F)无「不可用」级差评;
- 产出:记录表+失败问题单+待查清单+收尾报告。
