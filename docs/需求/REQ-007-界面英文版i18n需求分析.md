# REQ-007:DeskPilot 界面英文版(i18n)——需求分析(评审稿 v0.2)

| 项 | 内容 |
|----|------|
| 需求号 | REQ-007 |
| 标题 | 人类可见 UI(审批/冻结/白名单管理/撤回确认/入白回执/托盘/告警气泡)全中文硬编码;英文主页上线后截图仍中文,英文 OS 用户看不懂。需求=按 OS 界面语言自动选择界面语言(zh-CN/en)+环境变量强制指定,文案目录单源化 |
| 优先 | **中高**(主页门面断裂+国际化用户面;sdfang 2026-09-20 指令:「页面上展示的弹框还是中文的,现在做需求分析」) |
| 状态 | **需求分析完成,待评审**(sdfang 审核稿) |
| 提出 | 2026-09-18/20 sdfang |

## 1. 背景与问题

- 主页已双语(英文默认),但 hero/演示 GIF/四张实拍截图里的**弹窗全中文**——英文访客看到的核心证据面读不懂;
- 英文 OS 用户实际使用时,审批窗/冻结卡/管理窗/撤回窗/托盘/告警气泡全部中文;
- 本质:界面语言跟随产品市场(国际化),但文案是 ~96 处散落硬编码,无目录、无探测、无切换机制。

## 2. 文案面盘点(2026-09-20 代码实证)

| 面 | 规模 | 形态 |
|----|------|------|
| approval_dialog.py | ~10 | 标题/倒计时/四按钮(批准一次/此后同类允许/永久加入/拒绝)/提示 |
| freeze_dialog.py | ~18 | 「DeskPilot 急停」/写操作全拒句/「立即解冻/稍后提醒」/热键行/触发来源与时间 |
| whitelist_window.py | ~31 | 管理窗标题/搜索/两分区标题/「移出/清空/撤销」/撤回确认窗+倒计时默认保留 |
| tray.py | ~7 | 托盘菜单/死亡告警气泡 |
| dialog_service.py | ~10 | 线程内提示 |
| enforcement.py 动态模板 | ~20 | 审批描述「AI 请求操作新应用「X」」/来源标注/取证底注(已置前取证/本次无实拍/无可见窗口)/入白三态含义 |
| **合计** | **~96** | 全部硬编码中文 |

## 3. 范围划定(v1)

**进**:§2 六面全部(静态文案+动态模板)。**不进**(明示):
- MCP 错误消息(受众=AI,语言无关的自愈语义;v2 候选);
- 审计事件名(追溯兼容性:改名破钉测试与历史检索)——保持中文并文档注明;
- 错误码名/文件协议名/单据与详设文档。

## 4. 方案(推荐 ①)

**轻量目录模块 `deskpilot/i18n.py`**:
- 结构:`{key: {"zh-CN": ..., "en": ...}}` 单层目录(新增文案=注册一行,符合注册表纪律);`tr(key, **fmt)` 取词;
- 探测:复用 appnames 已有的 `_preferred_ui_languages()`(GetUserPreferredUILanguages,MUI 同源通道),提升至共享位;
- 覆盖:`DESKPILOT_LOCALE=en|zh-CN` 环境变量强制(测试与英文素材生成的开关);
- 回退:缺键按 zh-CN + 记审计「i18n 缺键」(fail-closed,不静默英文缺失)。

备选:② gettext/babel 全框架(重,96 键用不上复数体系);③ 双语硬编码并列(分叉,否决)。

## 5. 关键风险与对策(实证)

| 风险 | 证据 | 对策 |
|------|------|------|
| **布局溢出**:英文按钮更长("批准一次"4 字 → "Approve once" 12 字),审批窗定宽 480、按钮按字符宽排布,四按钮右排可能溢出 | approval_dialog.py:19 `_WIDTH=480`、:34 `_BTN_WIDTH` | 按钮文案按语言自适应宽度(英文放大按钮宽度/允许双行);四类弹窗英文渲染后逐张目视(有 UI 改动必看效果) |
| **窗口标题切换**:既有代码按中文标题找窗(focus_existing_or_exit("DeskPilot 白名单管理")/find_window 类断言) | whitelist_window 单例、测试窗口定位 | 标题与单例键改为**语言无关匹配**(标题前缀 "DeskPilot" 恒定,或单例匹配双语标题) |
| **测试面**:test_enrollshot_iss73 钉中文描述文本(显示名来源/未经系统核验/本次无实拍) | tests/test_enrollshot_iss73.py | 测试默认锁 `DESKPILOT_LOCALE=zh-CN`(既有断言不动);en 形态用例单独加(原文案 en 断言) |
| **动态模板**:enforcement 描述带格式槽(进程名/路径/计数),翻译须保槽位与语序 | enforcement.py _describe/_describe_enroll | 模板键带 `{}` 槽,目录内两语言各自语序;槽内容(进程名/路径)不译 |
| **审计事件名不改** | 全库钉测试与历史审计 | 目录显式排除;文档注明 |

## 6. 验收口径

- 英文 OS 界面语言下:四类弹窗+托盘+气泡+动态描述全英文且布局不破(逐张目视);zh-CN 下全中文零回归;
- `DESKPILOT_LOCALE=en` 强制英文(与 OS 无关);
- i18n 目录完备性钉:代码取词键 ⊆ 目录,且 zh-CN/en 键集相等(缺键即红);
- 既有套件全绿(测试默认锁 zh-CN);
- 英文素材重制:hero/4 截图/demo.gif 用 `DESKPILOT_LOCALE=en` 重录(REQ-006 视觉面的闭环)。

## 7. 测试设计(五要素骨架)

- 单元:目录完备性/双键集相等/缺键回退+审计;
- 单元:Tk 替身渲染四类弹窗,DESKPILOT_LOCALE 切换下标题/按钮文本断言(en+zh);
- 单元:enforcement 动态模板双语言产出(槽位注入正确);
- 集成:真 daemon 弹窗构建,英文界面下渲染树**无残留中文**(形态扫描);
- 回归:全量(锁 zh-CN 后既有断言零改动为目标)。

## 8. 分期

- **P1(本单)**:i18n 目录+探测+六面迁移+布局自适应+钉测试;
- **P2(随单)**:英文素材重制(4 截图+hero+demo.gif 英文版)+英文版 Release 说明同步;
- v2 候选:MCP 错误消息英化评估。
