# REQ-007:DeskPilot 界面英文版(i18n)——人类可见面多语言化

| 项 | 内容 |
|----|------|
| 需求号 | REQ-007 |
| 标题 | 弹窗/托盘/管理窗等**人类可见 UI** 目前全中文硬编码,英文 OS 用户(及英文主页访客)看不懂;需求=按 OS 界面语言自动选择界面语言(zh-CN/en),支持环境变量强制指定(供测试与主页素材生成),文案目录单源化 |
| 优先 | **中高**(英文主页已上线,截图全部中文=门面断裂;国际化用户面) |
| 状态 | **需求分析完成,待评审**(2026-09-20;sdfang 指令:「提个需求,看怎么上一下英文版。你做需求分析,我来审核」) |
| 提出 | 2026-09-18/20 sdfang:「当前主页一些截图,都是中文的,老外还是看不懂,我们的 deskpilot 不支持英文版」 |

## 1. 文案面盘点(2026-09-20 代码实证)

| 面 | 规模 | 内容形态 |
|----|------|---------|
| approval_dialog.py | ~10 条 | 标题「DeskPilot 审批」、倒计时「N 秒默认拒绝」、按钮「批准一次/本次会话允许/永久加入/拒绝」、提权/审批链提示 |
| freeze_dialog.py | ~18 条 | 「DeskPilot 急停」「AI 的写操作已全部拒绝(EMERGENCY_STOP)」「立即解冻/稍后提醒」、热键提示行、触发来源与时间 |
| whitelist_window.py | ~31 条 | 管理窗标题、搜索/分区标题(永久白名单/本次会话允许)、「移出/清空/撤销」、撤回确认窗「AI 请求将 X 移出白名单」+倒计时「N 秒默认保留」 |
| tray.py | ~7 条 | 托盘菜单「白名单管理/退出」、死亡告警气泡「守护进程不在…」 |
| dialog_service.py | ~10 条 | 弹窗线程内提示类 |
| enforcement.py 动态描述 | ~20 条 | 审批描述模板「AI 请求操作新应用「X」」「显示名来源:…自报,未经系统核验」、取证底注「已置前取证/本次无实拍,请谨慎裁决/该软件当前无可见窗口」、入白三态含义段 |
| **合计** | **~96 条** | 硬编码中文,无目录化 |

## 2. 范围划定(建议,v1)

**进**:上表全部人类可见 UI(六面)。**不进**(明示):
- MCP 错误消息(受众是 AI,AI 多语言可读;且 ISS-0027 的 AI 自愈指引语义与语言无关)——v2 候选;
- 审计事件名(追溯兼容性:改事件名会破钉测试与历史审计检索)——保持中文,文档注明;
- 单据/设计文档(本身是中文工程资产)。

## 3. 方案选项

| # | 方案 | 评估 |
|---|------|------|
| ①(**推荐**) | **轻量目录模块 `deskpilot/i18n.py`**:键→{zh-CN, en} 双语文本表;`tr(key, **fmt)` 取词;语言探测复用 appnames 已有的 `_preferred_ui_languages()`(GetUserPreferredUILanguages,MUI 解析同源通道)提升到共享位;`DESKPILOT_LOCALE` 环境变量强制覆盖(测试/素材生成) | 单源目录、零框架依赖、与既有 MUI 通道同族;~96 键一次目录化 |
| ② | 引入 gettext/babel 全框架 | 重;打包增依赖;96 键用不上其复数/日期体系 |
| ③ | 双语硬编码并列(每文案处两串) | 维护分叉,否决 |

## 4. 验收口径(要点)

- 英文 OS 界面语言下:四类弹窗(审批/冻结/管理窗/撤回确认)+托盘菜单+死亡告警气泡全部英文;zh-CN 下全中文;
- `DESKPILOT_LOCALE=en` 强制英文(与 OS 语言无关)——主页英文素材截图/GIF 由此生成;
- 语言目录完备性钉:代码引用的键 ⊆ 目录,且两语言键集相等(钉测试);
- 弹窗既有布局/落位/动画零回归(ISS-0058/0071 成果不破);
- 审计事件名/错误码不变(钉测试守护)。

## 5. 测试设计(五要素,评审后细化)

- 单元:catalog 完备性钉(扫描六模块取词调用 vs 目录键集);双语言键集相等;
- 单元:Tk 替身渲染四类弹窗,断言按钮/标题文案随 `DESKPILOT_LOCALE` 切换(en/zh);
- 单元:动态描述模板(enforcement)按语言产出英文/中文形态,格式参数注入正确;
- 集成:OS 语言探测缝替身 + 真弹窗构建,英文界面完整无残留中文(形态扫描渲染树);
- 回归:全量套件(弹窗文案断言的既有用例适配备案)。

## 6. 实施分期建议

- **P1(本单)**:i18n 目录模块+探测+六面文案迁移+钉测试;
- **P2(随单或紧接)**:主页英文素材重制(4 张截图+demo.gif 英文版,`DESKPILOT_LOCALE=en` 录制);
- P3(候选 v2):MCP 错误消息英化评估。

## 7. 约束

- 文案目录单源,禁止散落双语字面量;fail-closed:缺键按 zh-CN 回退并记审计(不静默英文缺失);
- 审计事件名/错误码/文件邮箱协议名不变;
- 实现走 SDD(P1 红→P2 核对→P3 绿)。
