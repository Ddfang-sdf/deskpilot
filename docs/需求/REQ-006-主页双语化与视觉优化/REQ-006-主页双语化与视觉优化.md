## 1. 借鉴分析(archify 主页实证拆解)

- **双语=平行文件+顶部互链**(English 默认 README.md ↔ README_ZH.md),非混排;
- **hero 图**紧随标题;**徽章行**(license/版本/平台);
- **证据优先**:真实产物(GIF/托管实例)而非效果图,明说「非 mockup」;
- **零摩擦**:一行安装+快速上手;
- **章节序**:标语→特性→徽章→链接→演示→预览→快速上手→细节→为什么→原理→安装矩阵→License→贡献→star 历史;
- **社交证明**:star 徽章/历史曲线。

## 3. 设计要点

- 英文版为重写(面向全球开发者),非逐字翻译;中文版=现有 README 内容精修+互链;
- hero 生成:**用运行中的 daemon 实拍**(get_clickable_map 的 SoM 标注图/审批弹窗截图),落 docs/assets/ 入库;
- 徽章用 shields.io 静态/动态徽章(github release 版本徽章+platform+license+CI 状态);
- 文案纪律:不写未实现功能(证据优先,引用真实手工测试记录/Release);
- 钉测试防漂移:互链/hero/徽章/配置块存在性入 tests/(文档钉先例:test_docspin_iss67_68)。

## 4. 约束

- 文档/资产改动为主,不动代码行为;
- hero 实拍须真实(daemon 生成),禁止 PS/编造;
- 既有 README 中文内容不丢(迁入中文版);
- 实现走 SDD(钉测试 P1 红→P3 绿)。
