## 侦察证据归档(2026-09-08,支持 D-05/D-10)

**原"UIA 定位失效"真相**:两个独立原因,均非 UIA 缺陷——
① 调用形态错误:get_ui_tree 的 window 参数接受 int hwnd 或标题字符串,
   当时传入 dict → 按 dict repr 做标题查找 → WINDOW_GONE;
② Progman hwnd 易变:实测 hwnd 131500 → 65896(explorer 重启后重建),
   旧 hwnd IsWindow=False → WINDOW_GONE。
结论:list_desktop_icons 必须每次调用动态定位桌面容器,禁止缓存 hwnd。

**三路实测(Win11 26200,本机 30 图标)**:

| 路 | 结果 | 产出 |
|----|------|------|
| UIA 树(get_ui_tree,新 hwnd) | ✓ | 全部 30 图标 display+cell_rect,一次调用,既有通道零新依赖 |
| LVM_GETITEMRECT LVIR_ICON(跨进程 VirtualAllocEx) | ✓ | graphic_rect(如 item0: [0,5,76,57]) |
| IShellWindows→IServiceProvider→IShellBrowser→QueryActiveShellView→IFolderView→Items(IEnumIDList)→SHGetPathFromIDListW | ✓ | source 路径(如 …\Desktop\Visual Studio Code.lnk);虚拟项(回收站)如实为 null |
| lParam→PIDL | ✗ | Win11 实测 lParam 恒 0,此路废弃 |

**关键接口教训**:跨进程 SendMessage 必须 VirtualAllocEx+ReadProcessMemory
(本进程地址空间对 explorer 不可读);IShellWindows 须以 IDispatch 派生
(vtbl 槽位含 4 个 dispatch 方法);FindWindowSW 须 SWFO_INCLUDEPENDING(0x1)
才返回可用 dispatch。**序对齐假设(A-2)**:三路计数一致(30=30=30),
序一致性在实现期以 item0=回收站 三路口径校验留痕。
