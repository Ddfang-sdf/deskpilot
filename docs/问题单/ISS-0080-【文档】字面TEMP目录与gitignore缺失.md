## 1. 根因(实证链)

### 1.1 现象

`git status --porcelain` → `?? %TEMP%/`;`find '%TEMP%' -type f` → `%TEMP%/nf_test.gif`(309B);全仓 `grep` 无任何 `.py` 引用该路径。

### 1.2 根因

`docs/手工测试计划-20260908-v1.md:24`(修复前):

```
| P-04 | `policy.local.yml` 备份(入白类用例会改写) | 复制到 %TEMP% 备查 |
```

`%TEMP%` 是 **cmd.exe / PowerShell 的变量语法**;**bash(Git Bash)不展开 `%VAR%`**——`cp x %TEMP%/` 在 bash 下被解释为相对路径 `./%TEMP%/`,于是原地建出字面目录并写入。

**机制层**:这是**跨 shell 变量语法混用**。同类风险已在项目记忆里登记过(交叉面清单:跨语言/跨 shell 脚本检查单),本次是又一实例。

### 1.3 为什么没被立刻发现

- `.gitignore` 无 TEMP 相关条目 → 目录直接出现在 `git status`;
- 目录名以 `%` 开头,**按 ASCII 排序靠前**,但 `git status` 未按首字符高亮,人工审阅易滑过;
- 内容仅 309B 的 gif,不占空间,不触发任何告警。

```
# 手工测试 P-04 备份目录误写字面量(2026-09-10 清理;根因是 bash 不展开 %TEMP%)

```
