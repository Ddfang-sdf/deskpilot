## 1. 背景(实证)

2026-09-10 11:42,daemon(--daemon)启动约 15s 后:
- 首个 /call(move)→ **HTTP 500 Internal Server Error**(urllib HTTPError,
  非结构化 JSON 错误体);
- 立即重试同调用 → ok=True;此后 /health、move、get_cursor 全正常。
- 与手工测试记录待查②(daemon 间歇性 /call 挂起自愈,/health 仍活)
  疑为同族:启动期初始化竞态(组件装配未完成时 /call 已可达)。

## 2. 待诊断方向(评审后定)

| # | 方向 |

## 4. 诊断结论(2026-09-17,证据分级,禁止臆断纪律执行)

**实证(盘上/源码铁证)**:
1. 「裸 500」观感根因=**客户端吞错误体**:handler 的 500 兜底(httpd.py:331-337)本就带结构化 JSON 体,但 `remote_call` 把 HTTPError(OSError 子类)吞进 `RuntimeError("无法连接…")`——错误体丢弃**且误归因**(服务明明连得上)。AI-first 底线缺陷,**已修**(HTTPError 分支解析错误体原样送达;t52a 红→绿,t52c 连接真失败语义钉绿)。
2. **move 路径 pyautogui FAILSAFE 未收敛**(core.py:298-301 裸调 moveTo;兄弟路径 click/key/type/drag 皆有收敛 :905/:959/:1075/:1104/execute :148)——光标压角时首调 move 必抛 FailSafeException → _run_sensing 只接 ExecutorError → 裸逃 → 兜底 500。与 09-10 现场吻合(ISS-0049 甩角实测期间,光标恰压角);**已修**(move 收敛 EMERGENCY_STOP;t52b 红→绿)。

**不坐实(如实标注)**:「立即重试即恢复」与光标压角候选不完全吻合(压角未解除时重试应再失败)——09-10 现场的真实诱因无法事后取证(dist/audit/daemon-stderr.log 仅余 WinError 10053 客户端中止噪音,无时间戳;结构化 500 不落 traceback)。**根因维持「候选未坐实」**;若再现,遗嘱/心跳(ISS-0084)+本次结构化错误体即为证据起点。待查②并案线索维持。
