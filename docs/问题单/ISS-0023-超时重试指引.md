# ISS-0023：TOOL_TIMEOUT 重试指引——错误体带 retry_after_ms 与建议次数

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0023 |
| 标题 | 超时预算触发仅说"处理中，请稍后重试"(httpd.py:281)，无重试参数，AI 不知何时重试/几次；外部实录首次 attach 撞错后盲目重试 |
| 严重级 | **低**（体验打磨；自愈路径已存在但靠猜） |
| 状态 | **实现完成,457 用例全绿(唯一红=ISS-0018 哈希另案),待实盘验收** |
| 提出 | 2026-09-03（外部 40 次调用实录反馈） |

## 1. 问题现状

外部 AI 首次 attach 收到 `TOOL_TIMEOUT("处理中，请稍后重试")`——
错误体 data=null，无间隔/次数指引，AI 只能盲目重试（运气好一次
就成功，但可能过密重试加重拥塞，或过晚重试浪费任务时长）。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **错误体缺重试元数据** | 超时预算设计（ISS-0009 §6）只定义了"返回处理中",未定义"何时再来" |

## 3. 整改方案

| 项 | 内容 |
|----|------|
| A | **响应 data 结构化**:`data` 由 null 改为 `{"retry_after_ms": <按级别>, "retry_max": 3}`。取值：L0/L1/L2 撞预算 → 500ms（预算内余量已耗尽，立刻可再试一轮）;L3（预算=approval_ttl+5，语义=审批挂起）→ 2000ms（审批通道排队中，密集重试无意义） |
| B | **message 同步**:`处理中，请稍后重试（建议 {N}ms 后，最多 {M} 次）` |

### 约束

- `error_code` 与 message 前缀"处理中"不变（向后兼容），只追加；
- 取值为常量表（随 TOOL_TIME_BUDGETS 同文件维护，单源），不做动态
  拥塞估计（过度设计）;
- 服务端"处理中继续执行"语义不变——重试指引不改变 ISS-0009 行为模型。

## 4. 测试设计（五要素）

层级：单元（响应构造函数直出）+ 集成（真 HttpDaemon 慢 probe 制造真实超时）。

| 用例 | 场景 | 前提 | 步骤 | 预期结果 | 断言代码 |
|------|------|------|------|----------|----------|
| TC-RT-01 | 预算级重试元数据（单元） | 响应构造函数（方案落地后的接缝） | 构造 L1 预算超时响应 | `error_code==TOOL_TIMEOUT` 且 `data.retry_after_ms==500`、`data.retry_max==3` | 返回 dict 字段直出 |
| TC-RT-02 | L3 语义差异化（单元） | 同上 | 构造 L3 响应 | `retry_after_ms==2000`;message 含"2000"与"最多 3 次"（自检修正：裸"3"子串太弱会误匹配，断言短语形态） | 返回 dict/message 子串直出 |
| TC-RT-03 | 真链路形态（集成） | 真 HttpDaemon(port=0)+慢 probe(sleep>预算） | HTTP POST /call 一个 L0 工具 | HTTP 200 且响应体同形（error_code/data/message 三要素齐） | 响应体 JSON 字段直出（形态断言 R3) |

装配守门：R1 单元层构造接缝不经过 HTTP；集成层真 daemon 真 socket，
仅 probe 注入慢（接缝替身，不 mock 产品函数）;R5 终效应=HTTP 响应体。

## 5. 施工接缝与装配矩阵(v0.2 评审稿)

### 入口链(全实名)

| 项 | 现场 | 改法 |
|----|------|------|
| 超时响应分支 | httpd.py:278-284(`result is daemon._BUDGET_EXCEEDED` → `_send(200, {...,"data": None})`) | 改调 `tool_timeout_payload(tool)` 构造完整响应体 |
| level 获取 | handler 分支已有 `tool` 名,直查 `TOOL_LEVELS.get(tool)`(httpd.py:124 同款查法,无需改 sentinel 形态) | — |
| 常量单源 | models.py TOOL_TIME_BUDGETS(models.py:39-41)旁新增 `RETRY_AFTER_MS = {"L3": 2000, "default": 500}`、`RETRY_MAX = 3` | 新常量,不复制进 httpd 字面量 |
| 构造接缝(新) | httpd 模块级 `tool_timeout_payload(tool: str) -> dict` | 返回完整响应 dict(ok/error_code/message/data 四要素),**单元测试直出** |

### R1 装配矩阵

| 用例 | daemon | probe | 断言面 |
|------|--------|-------|--------|
| TC-RT-01/02 | 不需 | 不需 | `tool_timeout_payload(...)` 返回 dict 直出 |
| TC-RT-03 | 真 HttpDaemon(port=0) | 慢 probe 替身(sleep 6s>L0 预算 5s)注入 Executor(probe=...) | 真 HTTP POST /call find_window(L0) → 响应体 JSON 四要素+数值(形态断言) |

注:L0 只读路径不走写锁(httpd.py:131-133),慢 probe 只拖慢单次
future,不影响其他测试;daemon stop() 在 finally 兜底。
