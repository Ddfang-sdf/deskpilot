# ISS-0070:【AI友好】type_element 空选择器指引缺失——"至少一项必填"没写进描述

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0070 |
| 标题 | type_element 全部选择器为空时返回 AMBIGUOUS(行为正确,fail-closed),但工具描述未写"name/control_type/index 至少一项必填",AI 容易空手调用撞 AMBIGUOUS 后不知如何修 |
| 严重级 | 低(描述指引) |
| 状态 | 建单待评审 |
| 提出 | 2026-09-08 手工测试 C-06 待查⑪;2026-09-10 转正建单 |

## 现象与证据

C-06 实测:空选择器 → AMBIGUOUS。行为对(不许盲打),但错误消息与
描述都没把"至少给一个定位条件"说给 AI 听。

## 方向

描述补"至少一项定位必填(name/control_type/index)"+AMBIGUOUS 错误
消息附同句指引(AI 可自愈:下一轮带条件重试)。约束:仅描述与错误
文案,判定逻辑不动;用例=空选择器错误消息含指引(直出)。
