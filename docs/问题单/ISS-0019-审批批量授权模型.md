# ISS-0019：审批批量授权模型

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0019 |
| 标题 | 终端类/L3 场景逐操作审批形成审批风暴与写锁串联（6 操作 1 批 1 超时 4 堵死实证）；引入"批量授权"（同窗口同工具会话内后续同类免批） |
| 严重级 | **中**（需求演进：长任务流/AI 驱动 AI 场景下逐操作审批不可用） |
| 状态 | **实现完成，1 项约束自洽性缺陷待 sdfang 裁决**（见 §6） |
| 提出 | 2026-09-02（Agent 驱动另一个 Claude 终端实证：逐操作审批串联超时） |

## 1. 问题现状

1. **审批风暴**：终端类进程（windowsterminal.exe）attach 即 L3，每个操作
   都弹审批；Agent 连续 6 个操作：1 批准、1 超时、4 个被写锁串联堵死
   （2026-09-01 实证，审计 seq 15~16 + 结果文件）。
2. **写锁串联**：审批 90s 倒计时持有写锁，后续调用全部排队饿死。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **审批粒度恒为单操作** | 无"对该窗口/该工具的连续操作"授权单元 |
| R2 | **审批等待持写锁** | 风暴场景下写路径实质串行化死等 |

## 3. 整改方案（已实现）

| 项 | 内容 |
|----|------|
| A | **授权范围**：`ApprovalToken.scope` = "once"(默认) / "window_session"（同一绑定窗口+同一工具，会话内后续同类免批）；令牌仅内存、随 daemon 会话消亡 |
| B | **弹窗批量选项**：常规 L3 审批弹窗新增「此后同类允许」按钮（结果文件写 `approve_session`）；通道词汇扩展 |
| C | **豁免面（按批准约束）**：终端类与 key 类永远逐操作，不适用批量（allow_scope=False 时批量裁决按 once 处理） |
| D | **查询接缝**：`ApprovalManager.session_scope_of(tool, binding_token)`；闸四批量命中不弹窗直接放行（执行前复核照常：急停/绑定有效性） |

### 约束

- 令牌仅内存态，不落盘；换窗口/换工具/过期即重新审批。
- 终端类不适用批量（保持逐操作）；L3 危险键不适用批量（保持逐次）。

## 4. 测试方案（已落地，427 全绿）

| 用例 | 断言 |
|------|------|
| approve_session 签发 | session_scope_of 返回 window_session（直出） |
| once 无范围 | 返回 None（直出） |
| 过期失效 | 时钟推进后返回 None（直出） |
| 终端豁免逐批 | 终端连续两操作弹窗计数 1→2（直出），无批量令牌 |

## 6. ⚠️ 待裁决：约束自洽性缺陷（晨报头号决策点）

**发现（实现期实证）**：当前闸四（eff==L3）的全部触发来源是
① 终端类 attach 和 ② L3 危险键——**两者都在豁免面内**。
批准的约束（终端类+危险键不适用批量）因此使批量授权**当前无任何生效面**：
能触发闸四的都被豁免，不被豁免的到不了闸四。

**证据**：白名单 max_level=L3 进程的普通操作（type_text，静态 L2）不过闸四；
终端/危险键过闸四但按约束豁免。

**待裁决选项**：
- 选项 1（推荐）：**终端类纳入批量**（批量正是为终端风暴而生），仅危险键保持逐次；终端批量按"同窗口同工具"范围授权，语义可控。
- 选项 2：维持现约束（批量授权作为未来 L3-cap 白名单条目的预备能力，当前空置）。
- 选项 3：引入白名单 max_level=L3 条目语义"该进程一切操作升 L3"（制造非豁免闸四来源），但改变现有白名单语义，影响面大。

## 7. 接口定义（SDD 公开入口）

| 入口 | 签名 | 语义 |
|------|------|------|
| `ApprovalToken.scope/tool/binding_token` | 字段 | 授权范围与适用面（仅内存） |
| `ApprovalManager.session_scope_of` | `(tool, binding_token) -> str \| None` | 有效 window_session 令牌查询（闸四判定接缝） |
| `ApprovalManager.request_approval`（行为变更） | `(description, fingerprint, image_path, target_rect, *, tool, binding_token, allow_scope) -> str` | 返回值域扩 "approve_session"；allow_scope=False 时批量按 once |
| `approval_dialog.build_window`（行为变更） | 常规审批增「此后同类允许」按钮 | 点击写 approve_session |
