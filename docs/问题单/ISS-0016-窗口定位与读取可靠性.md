# ISS-0016：窗口定位与读取可靠性（UIA COM 初始化 / 标题搜索本地化 / 错误分类）

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0016 |
| 标题 | get_ui_tree 经 daemon 报"尚未调用 CoInitialize"（两个 Claude 独立实证）；报错 WINDOW_GONE 笼统掩盖真因；find_window 按中文标题找不到英文标题应用 |
| 严重级 | **高**（UIA 系工具经 daemon 全挂，唯一目击路径是备用链降级；测试全绿只因执行层全是替身——装配盲区再现） |
| 状态 | 待评审（方案待 sdfang 审核） |
| 提出 | 2026-09-02（ISS-0015 验收测试一线：fresh Claude 报 WINDOW_GONE 并误判 UIPI 隔离；另见根因取证） |

## 1. 问题现状

1. **UIA 经 daemon 全挂**：`/call get_ui_tree` 返回 `INTERNAL_ERROR:
   [WinError -2147221008] 尚未调用 CoInitialize`（2026-09-01 /call 实证；
   2026-09-02 fresh Claude 独立撞见，报 WINDOW_GONE 后改用截图+OCR 备用链）。
   get_ui_tree / get_clickable_map / click_element / type_element / template_match
   等 UIA 系路径同病。测试全绿只因测试中 executor 全是替身——**经 daemon
   实调 UIA 的集成路径零覆盖**（R1 装配矩阵盲区，与 ISS-0013 同类）。
2. **报错掩盖真因**：COM 未初始化被笼统映射为"窗口无法前置/已消失"
   （WINDOW_GONE），引导用户与 Agent 向"提权/窗口消失"方向误判
   （fresh Claude 原话推断 UIPI 隔离，实非其因）。
3. **标题搜索本地化坑**：英文标题应用（Win11 记事本标题为
   "无标题 - Notepad"）按中文"记事本"查找无果（fresh Claude 找半天，
   最终靠进程名 notepad.exe 定位）；错误提示无"可改按进程名查找"指引。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **daemon 调用线程 COM 未初始化** | `httpd._call_with_budget` 每次调用新建 ThreadPoolExecutor 线程执行；uiautomation/COM 要求每线程 CoInitialize，新线程未初始化即调 UIA 全挂。executor 未做线程级惰性初始化 |
| R2 | **错误未分类** | COM 初始化失败/访问拒绝 与 窗口真消失 共用 WINDOW_GONE 出口，真因被吞 |
| R3 | **标题匹配单语且零指引** | find_window 仅按给定标题子串匹配，无本地化差异处理，无果时消息不含"改按进程名/hwnd"的下一步指引 |

## 3. 整改方案

### 3.1 总体

**UIA 入口线程级 COM 初始化幂等化；错误分类到具体原因；搜索无果给出下一步指引；配套补"经 daemon 实调 UIA"集成守门（消灭装配盲区）。**

### 3.2 整改项

| 项 | 内容 |
|----|------|
| A | **线程级 CoInitialize 幂等**：executor UIA 系入口统一经惰性初始化器（每线程首次调用 comtypes.CoInitialize，线程局部一次），daemon 任意线程上 UIA 可用；不得重复初始化（幂等）。 |
| B | **错误分类**：COM 初始化失败/RPC 不可用/访问拒绝 → `INTERNAL_ERROR` 且 message 含具体 WinError 与"UIA 通道异常"字样；仅窗口句柄失效/不可见 → `WINDOW_GONE`。报错文案不再引导向提权误判。 |
| C | **搜索无果指引**：find_window 零命中时 message 追加"可改按进程名（process）或句柄（hwnd）查找"；不引入翻译映射表（不自维护本地化）。 |
| D | **集成守门**：新增"经 daemon 实调"集成用例——真实 HttpDaemon + 真实 executor，对真实记事本窗口 get_ui_tree 返回非空元素（R1 装配矩阵补课）。 |
| E | **OCR/视觉分工描述**（随单微调）：ocr 描述补"要精确文字清单/文字定位时用我；要理解布局/图形时直接查看 screenshot 返回图像（多模态）"。 |

### 3.3 约束

- 初始化必须幂等（重复调用零副作用）；不向全局套线程模型（不改 httpd 线程结构）。
- 不自维护任何语言标题映射（通用性原则）。
- 只动 executor UIA 入口、错误映射、find_window 无果文案、ocr 描述；工具协议与 inputSchema 不变。
