## 2. 描述审计(6 条,资产落档;源文本行号以 2026-09-16 `mcp_server.py` 为准)

|---|------|-----------|------|------|
| 1 | server instructions `:308` | 「本服务截不到网页,只能截真实桌面」 | **不准确**:grep 坐实无浏览器拦截,screenshot 走 mss OS 级像素捕获,能截浏览器窗口像素。字面为假 → AI 两向误判(该截时放弃/把「能截」当「能操作」去点网页) | 精确划界:「**能**对浏览器窗口做 OS 级像素截屏,但**拿不到网页 DOM/结构**,对网页内容的 OS 级点击/输入**脆弱**;网页**操作**请用浏览器 MCP」 |
| 2 | server instructions + 6 工具 | 「请使用浏览器专用工具」(不具名) | **太含糊**:联邦下 AI 连了哪个浏览器 MCP 是环境相关;不具名 → 无法把提示映射到实际工具,只能猜或硬上 | 具名**类别+示例**:「请改用浏览器自动化 MCP(如 agent-browser / Playwright MCP / chrome-devtools-mcp;经 CDP 操作 DOM,比 OS 级截屏+坐标更准更稳)」——类别+示例可匹配工具清单又不硬耦合 |
