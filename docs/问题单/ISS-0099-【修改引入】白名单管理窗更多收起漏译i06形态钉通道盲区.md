## 0. 认账(修改引入)

REQ-007 迁移(i06 形态钉)把「裸中文 UI 字面量」的检测规则写成
「CJK 字符串 + 12 字符内见 text=」——只覆盖了 Label/Button 构造参数
通道,没覆盖 `_GraphicButton.set_state(...)` 这一运行时改文案通道。
迁移面因此漏掉两处,set_state 通道在英文形态下裸奔。钉的覆盖假定
错误,按修改引入认账。

## 1. 实证

- assets/screenshot-whitelist.png(2026-09-20 抓):「更多 3 项」中文
  按钮挂在英文窗口内;同图内「记事本/画图」为版本信息**数据**,不译,
  不在本单。
- 源码:whitelist_window.py:443 `more.set_state("收起", "up")`;
  :445 `more.set_state(f"更多 {rest} 项", "down")`。

## 2. 整改

- i18n.yml 增键:`wl.more`(en "More {n} items" / zh "更多 {n} 项")、
  `wl.collapse`(en "Collapse" / zh "收起");调用点改 tr() 带槽;
- i06 形态钉邻近词表扩展:`text=`、`set_state(`、`.title(` 三通道
  全覆盖(防第三类运行时改文案通道再漏)。
