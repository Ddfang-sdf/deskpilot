# ISS-0069:【AI友好】ocr 工具描述称支持 source="screen" 实则不接受

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0069 |
| 标题 | ocr 描述写"source=图像路径或屏幕区域",实测传 "screen" 被参数校验拒绝(描述与实现不一致);AI 按描述传 screen → 白撞一轮 |
| 严重级 | 低(描述一致性) |
| 状态 | 建单待评审 |
| 提出 | 2026-09-08 手工测试待查⑨;2026-09-10 转正建单 |

## 现象与证据

描述声称的"屏幕区域"形态在 schema/实现里不存在(source 仅路径/区域 rect);
"screen" 字面量直接被拒。

## 方向(评审二选一)

| # | 方向 |
|---|------|
| ① | 实现补 source="screen"(等价于 screenshot 全屏后 OCR——但已有 ocr:true 同参路径,可能重复能力) |
| ②(倾向) | 描述收紧:source 只写"图像路径 或 [l,t,r,b] 区域",并指向 screenshot(ocr:true) 组合用法——能力已有等价路径,描述别造假 |

约束:描述/实现/schema 三同步;用例=描述所宣称形态逐一实测命中。
