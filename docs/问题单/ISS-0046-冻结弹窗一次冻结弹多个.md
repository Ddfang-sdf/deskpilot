# ISS-0046：冻结弹窗一次冻结弹三个——孤儿进程各弹各的

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0046 |
| 标题 | 一次冻结弹出多个冻结通知框:N 个 deskpilot 进程各自的 FreezeNotifier/DialogService 独立触发、各弹各的;共享线程弹窗路径不经单例互斥 |
| 严重级 | **中**(观感与安全可信度;"急停有感知"变成"急停刷屏";与"守护进程十几个"同根因) |
| 状态 | **已修复(A 预检+竞态败者退出,B 互斥收口建窗点;C 由 A 覆盖;TC-46-01~04+既有互斥/复位 42 过)** |
| 提出 | 2026-09-09(sdfang 实证:每次冻结弹三个冻结框) |

## 1. 背景(实证+机制)

sdfang 实证:每次冻结弹出三个冻结通知框。代码取证:
- `freeze_notify.py:138-159` `_default_spawn`:有 DialogService 走共享线程
  弹窗(ISS-0008 P6),否则回退子进程;
- `freeze_dialog.py:326` `acquire_singleton`("Local\DeskPilotFreezeDialog"
  命名互斥)**只在子进程路径 main() 检查**;共享线程路径(dialog_service
  →build_window)**不经任何跨进程互斥**;
- 每个 deskpilot 进程的甩角轮询独立(`main._corner_loop` 各跑各的),
  甩角一次 → N 个进程各 _trigger → 各弹一个框。
- 今晚实证:双起竞争(手工 Start-Process 与代理自愈同时拉起)两次产生
  双 daemon(21012/4904、13868/13896)——与"守护进程十几个"同根因;
  N 个进程 = N 个冻结框。

注:freeze_notify.sync_local_with_shared_state 只同步复位(不同步触发),
该路径无责;estop._trigger 幂等(单进程一冻结一框)无责。

## 2. 整改方案(三层,治标+治本)

| 层 | 内容 | 性质 |
|----|------|------|
| A | **治本**:daemon 单例治理——端口占用即退出(9420 被占→新 daemon 显式退出/复用,不僵尸);僵尸自检(与"守护进程十几个"问题单合并或独立) | 根因 |
| B | **治标**:共享线程弹窗路径补跨进程守卫——build_window 前检查心跳锁(estop-dialog.lock,LOCK_MAX_AGE=3s 机制既有),多进程下也只弹一个 | 纵深防御 |
| C | 甩角/热键监听归属:仅端口属主 daemon 监听甩角(非属主 daemon 不起 corner 轮询线程) | 防多源触发 |

### 约束

- A 与"守护进程僵尸"治理是同一工程,评审时决定是否并单;
- 急停语义不变:冻结/复位/弹窗内容不动,只修"弹几个";
- 测试设计(五要素)于评审通过后产出:核心用例——两进程共存时冻结
  仅弹一框(替身 spawn 计数直出)+端口占用即退出(直出)。
