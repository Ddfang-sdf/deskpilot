# ISS-0025：测试环境隔离——默认套件不触生产环境与真实软件

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0025 |
| 标题 | 默认 pytest 读生产目录(dist\policy.yml)且拉起真实记事本——测试依赖生产环境,违反隔离原则;真机集成改显式 opt-in,哈希守卫搬回构建 |
| 严重级 | **中**（测试卫生/开源体验;间接解决 ISS-0018 哈希红） |
| 状态 | **建单,待评审** |
| 提出 | 2026-09-04(sdfang 指出"测试依赖生产环境本身就不对",复盘 09-01"不要开一堆窗口"指令只治标未治本) |

## 1. 问题现状

1. **默认套件读生产目录**:`test_paths_iss18` 哈希用例比对 repo 与
   `dist\policy.yml`——dist 是 daemon 运行期写入对象(用户永久入白落
   盘处),生产状态一变测试即红(当前唯一红,实证)。
2. **默认套件拉起真实软件**:`test_uia_com_iss16` / `test_clicktext_iss21`
   默认运行 spawn 真实记事本(Store 版,多窗口+会话恢复)——贡献者
   clone 后 `pytest` 桌面弹窗,与 09-01 开源体验要求直接冲突。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **真机集成未 opt-in 化** | `@pytest.mark.integration` 存在但未注册、无默认 skip,默认全跑 |
| R2 | **哈希守卫放错生命周期** | 它守"构建同步",却放在运行时 pytest 里,注定读生产 |
| R3 | **默认/集成未分层** | 未定义"默认套件零副作用"的硬边界 |

## 3. 整改方案

| 项 | 内容 |
|----|------|
| A | **默认零副作用**:注册 `integration` 标记;pyproject 默认 `-m "not integration"` 跳过;新增 `--run-integration` 显式开关。默认 `pytest` 不写任何生产目录、不 spawn 任何 GUI 进程 |
| B | **真机价值保留**:集成用例本身不动(装配守门抓真 bug 的证据链保持),只改默认开关;CI windows runner 显式 `--run-integration` 全量跑(受控环境,防集成腐化) |
| C | **哈希守卫搬回构建**:新增纯函数 `verify_policy_sync(src, dst)`(读两文件比对,临时目录可用);由构建流程(pyinstaller 前/后同步步骤)与 CI 构建后校验调用;pytest 用例改为临时目录验证该纯函数,不再读 dist |
| D | **文档**:README/CONTRIBUTING 写明默认套件零副作用、真机集成需 `--run-integration`(会开记事本) |

### 约束

- 集成断言强度不减(不因 opt-in 而放松);
- 默认运行不触:dist/、audit 生产目录、任何真实 GUI 进程;
- 读型 OS 查询(monitors/Get-StartApps)保持默认(只读无害),但其环境
  容差单独复核,不属本单范围。

## 4. 测试设计(五要素;本单是测试基建改造,自身用例)

层级:单元(verify_policy_sync 纯函数)+ 系统外表面(进程计数/收集统计)。

| 用例 | 场景 | 前提 | 步骤 | 预期结果 | 断言代码 |
|------|------|------|------|----------|----------|
| TC-ENV-01 | 默认运行零 GUI 副作用 | 桌面无记事本 | `pytest tests -q`(无开关) | 全绿且 notepad 进程数运行前后不变 | 前后 `Get-Process notepad` 计数相等(系统外表面) |
| TC-ENV-02 | 开关显式启用真机 | 同上 | `pytest -m integration` 单跑 notepad 集成 1 条 | 用例执行(控制时长) | 收集/通过计数(直出) |
| TC-ENV-03 | 同步校验纯函数:相同通过(单元) | 临时目录两同内容 policy | `verify_policy_sync(src, dst)` | 返回 True | 返回值直出 |
| TC-ENV-04 | 同步校验纯函数:不同报错(单元) | 临时目录两不同内容 | 同上 | 抛错/返回 False 且不涉及任何生产路径 | 返回值+异常直出 |
| TC-ENV-05 | 旧哈希用例已不再读 dist | — | 收集 `tests/test_paths_iss18.py` | 其内无任何对 `dist\` 的路径引用 | 源码静态断言(形态) |

装配守门:R1 真机组合仅 TC-ENV-02(显式开关);R2 单元层纯函数零打桩;
R3 收集统计直出;R4 本单路径变迁=test_paths_iss18 改临时目录、pyproject
标记注册;R5 终效应=默认运行前后 notepad 进程数不变(TC-ENV-01)。
