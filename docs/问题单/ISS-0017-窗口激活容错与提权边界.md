# ISS-0017：窗口激活容错与提权边界

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0017 |
| 标题 | activate_window 对最小化窗口"无法前置"（前台锁无容错）；目标应用提权时输入被 UIPI 静默丢弃且返回 ok=True（fail-open 体验） |
| 严重级 | **高**（安全语义：写操作"看起来成功实际没发生"——fail-closed 原则被静默违反；UIPI 确诊实证） |
| 状态 | 待评审（方案待 sdfang 审核） |
| 提出 | 2026-09-01（西柚重连排查实证：activate 失败于最小化；提权 daemon 后点击即中） |

## 1. 问题现状

1. **activate_window 对最小化窗口失败**：目标窗口最小化时返回
   "窗口无法前置（可能已消失）"（2026-09-01 实证）；窗口实际存在，
   手工 SW_RESTORE 后即可正常——activate 不做还原、对 Windows 前台锁
   无退避容错。
2. **提权目标输入静默丢弃**：目标进程提权运行（如西柚加速器）时，
   非提权 daemon 的 SendInput 被 UIPI（用户界面权限隔离）静默丢弃；
   click/key/type_text 全部返回 **ok=True 但无任何效果**（2026-09-01
   实证：提权重启 daemon 后同一坐标点击即生效，GitHub 200 佐证）。
   这是"静默降级"，直接违反 fail-closed 原则。
3. **遮挡误击**：目标窗口被遮挡时像素点击打在上层窗口（本单记录现象，
   处置并入方案 B 的可达性检查）。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **activate 只调 SetForegroundWindow** | 不先 SW_RESTORE（最小化不可前置）、不处理 Windows 前台锁（后台进程无前台权时成功假象），成功语义未校验 |
| R2 | **写路径无完整性级别检测** | 未比较目标进程与自身进程的提权级别；UIPI 丢弃是系统级静默行为，应用层不检测就必然 ok=True 假象 |
| R3 | **可达性未校验** | 写操作前不确认"目标窗口前台且未被遮挡"，遮挡时事件落在别窗 |

## 3. 整改方案

### 3.1 总体

**激活带容错（还原+前台锁退避）；写前完整性检测（提权高于自身即显式报错，禁止静默）；写前可达性校验（前台+遮挡）。**

### 3.2 整改项

| 项 | 内容 |
|----|------|
| A | **activate_window 容错**：序列改为 `SW_RESTORE → SetForegroundWindow`；前台锁失败按短退避重试；最终失败返回 `WINDOW_GONE` 并注明"可能处于最小化/前台锁"——绝不成功假象。 |
| B | **写前完整性检测（fail-closed）**：写操作（click/key/type_text/type_element/click_element/drag/scroll/set_clipboard/activate_window）执行前比较目标进程与自身进程的提权级别（OpenProcessToken + TokenElevationType/完整性级别）；目标更高 → 显式拒绝，新错误码 `ELEVATION_REQUIRED`（message 含"目标以管理员运行，请以管理员身份重启 daemon"）。 |
| C | **写前可达性校验**：像素级写操作前校验绑定窗口处于前台且落点在窗口矩形内无遮挡（既有 _check_point 扩展遮挡判定）；不可达显式报错而非盲打。 |
| D | **文档**：README/INSTALL 补"操作提权应用需提权启动 daemon（UAC 弹窗人类确认）"。 |

### 3.3 约束

- 检测失败的判定一律拒绝（fail-closed，禁止静默降级为现状的 ok=True）。
- 提权检测开销有界（OpenProcessToken 一次/绑定，缓存至 detach）。
- 不改变审批/白名单语义；终端类规则不动。

## 4. 测试方案

### 4.1 单元（先行）

| 用例 | 断言 |
|------|------|
| 激活序列含还原 | 激活调用记录含 SW_RESTORE 在前、SetForegroundWindow 在后（直出） |
| 提权比较-目标更高 | 注入目标 TokenElevationType=Full → 写操作拒绝 ELEVATION_REQUIRED（直出） |
| 提权比较-同级放行 | 注入同级 → 放行（直出） |
| 检测失败 fail-closed | 注入 OpenProcessToken 失败 → 拒绝（直出） |
| 遮挡判定 | 注入绑定矩形被它窗覆盖 → 拒绝且 message 含遮挡（直出） |

### 4.2 集成验收

- 全量 pytest 绿
- 实盘：最小化窗口 activate 成功；提权应用写操作显式 ELEVATION_REQUIRED（不再 ok=True 假象）
