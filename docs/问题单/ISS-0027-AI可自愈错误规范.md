# ISS-0027：AI 可自愈错误规范——参数回显制度化 + OCR 近邻建议

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0027 |
| 标题 | AI 收到错误后无法对比"我发的 vs 服务器收到的",传输类故障须试错诊断(中文乱码实证绕两圈);OCR 未命中无自愈通道。引入错误回显规范与近邻建议 |
| 严重级 | **中**（AI 友好基础设施;2026-09-04 sdfang 确立"AI 才是直接用户"原则后的首项落地） |
| 状态 | **建单,待评审** |
| 提出 | 2026-09-04（中文乱码复盘;sdfang 决策:做①③,②(U+FFFD 校验)不做） |

## 1. 问题现状

1. **AI 无法对比发送与接收**：乱码/转义/截断类故障下,AI 收到
   "未找到文字: ??"只能试错(实证:同一错误姿势重发一次才换通道),
   绕两圈。错误信息不含"服务器视角的参数"。
2. **未命中即死路**：OCR_TEXT_NOT_FOUND 只报摘要,无相似候选;
   OCR 误读/拼写差一字时,AI 无一轮自愈通道,只能退坐标重试。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **错误构造无回显规范** | 现有回显(KEY_UNKNOWN 清单/OCR 摘要)是散点行为,未制度化 |
| R2 | **not_found 无相似通道** | 设计只定义了"拒绝",未定义"帮 AI 找到相近项" |

## 3. 整改方案

| 项 | 内容 |
|----|------|
| A | **参数回显制度化**：所有参数类错误 message 必须含"服务端实际收到的参数值"——统一格式 `（收到: <截断值>）`;超长文本沿用 60 字截断。清扫面:enforcement._deny 各路径、executor 参数错误、tools 层校验、httpd 请求体错误 |
| B | **OCR 近邻建议**：新增纯函数 `suggest_similar(items, query, limit=3, min_ratio=0.5)`(difflib 现成);OCR_TEXT_NOT_FOUND 错误附"相似文本: X / Y"。**仅建议,绝不自动执行**——建议只存在于错误文本,无任何代码路径消费它,点击仍需 AI 发起正常调用过四道闸 |
| C | 错误 message 长度纪律(≤400 字符)对回显与建议同样生效(候选截断) |

### 约束

- U+FFFD 校验**不做**(sdfang 决策:它抓不住 GBK→合法 UTF-8 的静默变字,性价比不足);
- 回显对调用方零新信息(AI 本知道自己发了什么),但截断纪律必须守住(防日志膨胀);
- 建议必须是错误文本的一部分,响应 data 不得携带坐标/指令,杜绝"建议即执行"。

## 4. 测试设计(五要素)

层级:单元(纯函数/Decision 直出)为主,附既有集成回归。

| 用例 | 场景 | 前提 | 步骤 | 预期结果 | 断言代码 |
|------|------|------|------|----------|----------|
| TC-ECHO-01 | 参数错误带回显(单元) | 长文本参数触发 INVALID_PARAMS 类错误 | 构造调用 | message 含"收到:"与截断后的文本(≤60 字) | `d.message` 子串+长度断言(直出) |
| TC-ECHO-02 | 超长回显截断(单元) | 5000 字文本触发错误 | 同上 | 回显段 ≤60 字,总长 ≤400 | message 长度断言(直出) |
| TC-ECHO-03 | 既有回显不回归(单元) | 未收录键 | key=ctrl+shift+f99 | KEY_UNKNOWN 清单仍在(ISS-0022 行为) | message 子串(直出) |
| TC-FUZZ-01 | 无相似项不附建议(单元) | items 与 query 相似度 <0.5 | `suggest_similar(...)` | 返回空列表 | 返回值直出 |
| TC-FUZZ-02 | 相似项排序截断(单元) | 4 个候选,ratio 各异 | 同上 | 返回 ≤3 个,按 ratio 降序,首项为最相似 | 返回值列表直出 |
| TC-FUZZ-03 | 建议绝不执行(形态) | OCR 未命中含相似项 | 触发 OCR_TEXT_NOT_FOUND | 响应 data 为 null(无坐标/无指令载荷);message 含建议 | 响应体 data==None 断言(R3 形态) |
| TC-FUZZ-04 | 有相似项的 not_found 消息(集成回归) | 真 daemon+真 OCR(沿用 TC-CT 装配) | click_text 差一字查询 | error_code=OCR_TEXT_NOT_FOUND 且 message 含"相似文本" | HTTP 响应体直出 |

装配守门:R1 单元/集成矩阵沿用 ISS-0021 装配;R2 单元层仅纯函数零打桩;
R3 响应体形态断言(TC-FUZZ-03 锁死"建议无载荷");R4 无持久化路径变迁;
R5 终效应=错误文本可发现性(TC-FUZZ-04 真链)。

## 5. 施工接缝与自检校准点(v0.2 评审稿)

| 项 | 现场 | 改法 |
|----|------|------|
| 回显工具函数 | enforcement._truncate_show(text, limit) 已有 | 复用为回显截断;统一格式 `（收到: <截断>）` |
| 清扫面 | enforcement._deny 各路径参数类错误、executor 参数错误(click_text 系/INVALID_PARAMS)、tools 层校验、httpd 请求体错误 | 逐处补回显;不动非参数类错误(急停/窗口消失等) |
| 近邻建议(新纯函数) | deskpilot/executor/textclick.py `suggest_similar(items, query, limit=3, min_ratio=0.5)`(difflib) | TC-FUZZ-01/02 直出 |
| 接线点 | executor._click_text not_found 分支 | message 附"相似文本: ...";data 保持 None(TC-FUZZ-03 锁死无载荷) |
| **自检校准** | 建议不自动执行由架构保证:建议仅在错误文本,无消费路径 | TC-FUZZ-03 形态断言守护 |
