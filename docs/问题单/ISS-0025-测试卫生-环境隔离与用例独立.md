# ISS-0025：测试卫生——默认套件环境隔离 + 用例独立

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0025 |
| 标题 | 默认 pytest 读生产目录(dist\policy.yml)、拉起真实记事本、用例间顺序依赖——测试依赖生产环境且相互依赖;合并治理(原 ISS-0026 并入) |
| 严重级 | **中**（测试可信度与开源体验;sdfang 指示测试整改合并一单） |
| 状态 | **建单,待评审** |
| 提出 | 2026-09-04（sdfang 指出"测试依赖生产环境/相互依赖都不对";合并 ISS-0025+ISS-0026) |

## 1. 问题现状

1. **默认套件读生产目录**：`test_paths_iss18` 哈希用例比对 repo 与
   `dist\policy.yml`——daemon 运行期写入对象,生产状态一变测试即红
   (当前唯一红,实证)。
2. **默认套件拉起真实软件**：notepad 集成测试默认运行 spawn 真实
   记事本——贡献者 clone 后 `pytest` 桌面弹窗,违背 09-01 开源体验要求。
3. **用例顺序依赖**：`test_image_reference_kept_on_window` 单跑必挂
   (`Too early to create image: no default root window`,实证三连挂),
   全量靠前序残留假绿。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | **真机集成未 opt-in 化** | `@pytest.mark.integration` 存在但未注册、无默认 skip |
| R2 | **哈希守卫放错生命周期** | 它守"构建同步",却放在运行时 pytest 里,注定读生产 |
| R3 | **测试未自建环境** | tk 用例借前序测试残留的默认根窗口,无自治 |
| R4 | **无顺序依赖检测机制** | 无随机序执行暴露隐依赖,顺序绿长期掩盖 |

## 3. 整改方案

| 项 | 内容 |
|----|------|
| A | **默认零副作用**：注册 `integration` 标记;pyproject 默认 `-m "not integration"`;新增 `--run-integration` 显式开关。默认 `pytest` 不写生产目录、不 spawn GUI 进程 |
| B | **真机价值保留**：集成用例本身不动(装配守门抓真 bug 证据链保持),只改默认开关;CI windows runner 显式 `--run-integration` 全量跑 |
| C | **哈希守卫搬回构建**：纯函数 `verify_policy_sync(src, dst)` 由构建/CI 调用;pytest 只在临时目录测该纯函数,不再读 dist |
| D | **用例自治**：tk 用例改注入替身 PhotoImage(记录实例),断言"窗口持有引用"落在替身上——零真实 tk、零根窗口依赖 |
| E | **随机序防护**：引入 pytest-randomly,CI 全量随机序执行,暴露并修治全部隐依赖;本地默认保持顺序 |
| F | **规范入册**：SDD 测试设计硬规则补"用例间零依赖:任何用例单跑必须绿";README/CONTRIBUTING 写明默认零副作用、真机需 `--run-integration` |

### 约束

- 集成断言强度不减(不因 opt-in 而放松);
- 默认运行不触:dist/、audit 生产目录、任何真实 GUI 进程;
- 读型 OS 查询(monitors/Get-StartApps)保持默认(只读无害),环境容差单独复核不属本单;
- 不借机改产品代码(纯测试卫生)。

## 4. 测试设计(五要素;本单自身用例)

| 用例 | 场景 | 前提 | 步骤 | 预期结果 | 断言代码 |
|------|------|------|------|----------|----------|
| TC-HY-01 | 默认运行零 GUI 副作用 | 桌面无记事本 | `pytest tests -q`(无开关) | 全绿且 notepad 进程数运行前后不变 | 前后进程计数相等(系统外表面) |
| TC-HY-02 | 开关显式启用真机 | 同上 | `pytest -m integration` 单跑 notepad 集成 1 条 | 用例执行 | 收集/通过计数(直出) |
| TC-HY-03 | 同步校验纯函数:相同通过(单元) | 临时目录两同内容 policy | `verify_policy_sync(src, dst)` | 返回 True | 返回值直出 |
| TC-HY-04 | 同步校验纯函数:不同报错(单元) | 临时目录两不同内容 | 同上 | 抛错/False 且不涉生产路径 | 返回值+异常直出 |
| TC-HY-05 | 旧哈希用例不再读 dist | — | 收集 tests/test_paths_iss18.py | 无任何对 `dist\` 的路径引用 | 源码静态断言(形态) |
| TC-HY-06 | 顺序依赖用例单跑绿 | 无前序依赖 | 单跑 test_image_reference_kept_on_window | 通过,零 RuntimeError | 退出码 0(系统外表面) |
| TC-HY-07 | 替身语义等价 | 假 PhotoImage 记录实例 | build_window(image_path=假图) | 窗口对象持有替身实例 | `isinstance(win._approval_photo, FakePhotoImage)`(直出) |
| TC-HY-08 | 随机序全量绿(CI) | pytest-randomly 已装 | CI `pytest tests -q`(随机序) | 全绿(排除已知另案) | CI 通过状态 |

装配守门:R1 真机组合仅 TC-HY-02(显式开关);R2 单元层零打桩;
R3 形态/收集断言;R4 路径变迁=pyproject 标记注册+pytest-randomly、
test_paths_iss18 改临时目录;R5 终效应=默认运行前后 notepad 进程数
不变(TC-HY-01)与单跑退出码 0(TC-HY-06)。
