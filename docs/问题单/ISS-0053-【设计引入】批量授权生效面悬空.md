# ISS-0053:【设计引入】批量授权生效面悬空——许可键失忆+危险键静默降级双因

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0053 |
| 标题 | 「此后同类允许」三重失真:①许可键=binding_token,重绑/TTL/桌面 hwnd 易变全使之失忆;②key 类与终端类被 ISS-0019 豁免面排除,弹窗却照样显示批量按钮并静默降级为"批准一次"(esc 反复弹实证);③豁免面=L3 全部来源 → 批量授权出生即空转(ISS-0019 §6 悬 8 天未裁决) |

| 提出 | 2026-09-10(ISS-0043 B 层评审中考古 ISS-0019 发现同根;应 sdfang 要求分类建单) |

## 1. 定性(应 sdfang 要求明确分类)

**设计引入,非问题单解决引入。** 判据:修改引入=原本好使被改坏;而豁免面
是 ISS-0019 方案 v0.1 明文、2026-09-02 经 sdfang 批准的约束("按批准约束"),
批量授权**出生即空转**,无"曾经好使"时刻。加重项(弹窗对豁免类照显批量
按钮+静默降级)为 ISS-0019 实现期带出的 UX 缺陷,根仍在于设计未回答
"豁免类点批量按钮算什么"。

## 2. 考古链(证据)

| 日期 | 事实 | 出处 |
|------|------|------|
| 2026-09-01 | 终端审批风暴实证:6 操作 1 批 1 超时 4 串死 | ISS-0019 §1 |
| 2026-09-02 | ISS-0019 实现:scope 令牌+批量按钮+豁免面(按批准约束);实现期发现生效面为空,§6 挂起待裁决(三选项,推荐终端纳入) | ISS-0019 v0.2 + 晨报 §四 |
| 2026-09-08 | sdfang 被桌面 esc 反复弹窗(每次点批量每次都弹) | ISS-0043 §1 |
| 2026-09-10 | 读码发现 esc 之痛真因=豁免面静默降级(approval.py:98),非许可键记性;且 ISS-0019 当时排除按键的动机是"批量键粒度粗于危险粒度",**同键粒度当时没进方案** | 本次考古 |

设计动机重建:授权单元(工具+窗口)粒度表达不了危险边界时不批量——
终端载荷是自由文本(dir 与 rm -rf 同键),按键载荷是具体键位(esc 与
delete 同键)——动机本身成立。但:**按键的危险粒度就在键位上,同键批量
则粒度对齐,排除理由失效;终端的自由文本载荷永远无法对齐,维持排除。**

## 3. 整改方案(sdfang 2026-09-10 批准)

| 项 | 内容 |
|----|------|
| A | **许可键改 hwnd+tool**(ISS-0043 B①):重绑/TTL 不再失忆;桌面 hwnd 易变场景随窗口存活 |
| B | **key 类按同键粒度纳入批量**:session 令牌键=(tool, hwnd, norm_key);esc 免批绝不捎带 delete/alt+f4;终端类维持永远逐操作(载荷不可约束,结构上不批量) |
| C | **弹窗提示随语义更新**:A 层提示行改为"仅本次会话:同窗口同类操作免批(按键类=同键),daemon 重启后需重批"——"重新绑定需重批"不再为真,必须改 |
| D | **关 ISS-0019 §6 悬案**:不采"终端纳入批量"(当年推荐,今日判断其结构不安全);生效面由 key 类同键粒度填充 |

### 约束

- 终端类豁免不动(自由文本载荷无批量边界);
- 令牌仅内存、不落盘(持久许可 B② 不实施——未获授权);
- 跨窗/跨键/过期/重启即重新审批;执行前复核(急停/绑定有效)照常;
- 如实记险:hwnd 复用(窗关后被新窗复用句柄)下旧许可可能命中新窗——
  由"每次调用仍过绑定校验+白名单"兜底,残余风险接受并在文档明示。
