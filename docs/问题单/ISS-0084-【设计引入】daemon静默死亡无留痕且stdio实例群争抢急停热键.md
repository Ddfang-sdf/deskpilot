## 1. 现象与证据(2026-09-14 实测)

1. **9420 无属主**:`curl http://127.0.0.1:9420/health` → connection refused。
2. **无 daemon 进程**:4 个 `deskpilot.exe` 为 PyInstaller 引导+载荷成对 ×2,均为**无 `--daemon`** 的 stdio MCP 实例(两个 Claude 会话各起一个);无一守护进程。
3. **daemon 最后留痕**:`dist/audit/logs/audit-20260911.jsonl` 止于 **09-11 14:08「急停复位」**;`dist/audit/daemon-stderr.log` 止于 09-11 12:25,仅有「客户端中止连接」常规噪音,**无崩溃栈、无退出事件**。daemon 于 09-11 14:08 之后**静默死亡,死因未明**。
4. **死前探活史**:09-14 15:02/15:57 启动的 stdio 实例记「瘦代理跳过热键注册」——**当时 9420 仍有属主**(某个先起的 stdio 实例已升 full owner 占位)。
5. **争抢刷屏**:09-14 **20:22:49 起每分钟一条「急停热键注册失败」** 至今未停——9420 属主消失后,两个 stdio 实例都自认属主,`RegisterHotKey` 系统级单持有,输的一方每分钟重试并逐次审计。
6. **影响面**:白名单撤销/入白落盘走 daemon 原子写(ISS-0012),daemon 不在 → 撤销链不可用;急停复位热键的实际持有方是某个 stdio 实例,**不是设计属主 daemon**。

## 2. 根因(机制层)

1. **daemon 死亡无观测**:无心跳、无遗嘱(atexit/异常钩子)、无外部看门狗——进程消失不留任何痕迹,连「什么时候死的、怎么死的」都无从查起。**观测缺口是第一位的**:不补观测,死因排查无从开始。
2. **瘦代理协议只有半条命**(ISS-0002 缺口):stdio 实例启动时探活 daemon,在则瘦代理、不在则升 full owner;**但升级是一次性启动期决策,运行期不重探**——daemon 中途死亡后,各 stdio 实例永远停留在 owner 身份,且无互斥/让位协议。
3. **单例守门只管 daemon 对 daemon**(ISS-0046):daemon 不在时 **stdio 实例群之间没有属主仲裁**——系统级单持有资源(RegisterHotKey)于是变成「谁先抢到归谁、抢不到刷屏」。
4. 叠加既有开启单 ISS-0072(撤回墓碑被再次入白审批抹平),白名单撤销面当前为**双断**状态。

## 3. 整改方向(候选,评审裁定)

| # | 方向 | 说明 |
|---|------|------|
| ① | **daemon 存活观测** | 周期心跳落盘(刷新 `daemon-heartbeat` 戳)+ 退出遗嘱(atexit/异常钩子尽力落盘);为死因排查与死亡检测供数据 |
| ② | **热键属主协议** | stdio 升 owner 须先取互斥(命名 mutex/文件锁),且**daemon 复出时让位**(stdio 重探或 daemon 接管通告);争抢期间退避不刷屏(审计节流) |
| ③ | **daemon 死亡告警** | 经既有通知通道(FreezeNotifier 类)提示「守护进程不在,白名单管理/热键复位不可用」 |
| ⑤ | **开机自启动**(v0.3 增) | 用户登录自启(Run 键/计划任务/启动文件夹,形态评审定)——2026-09-15 实测:整机重启后 daemon 未被任何机制拉起,托盘(daemon 形态专属)消失;**当前全系统无任何 deskpilot 自启动项** |

## 4. 验收口径(要点,测试设计另立)

- daemon 进程消失 → 规定时限内**有告警留痕**;心跳断即被检出;
- daemon 死亡后任意数量 stdio 实例并存 → **急停热键注册失败审计零刷屏**(节流/让位协议生效);
- daemon 复出 → 热键属主**自动回迁** daemon,stdio 实例退回瘦代理;
- 白名单撤回落盘在 daemon 在时全链路可用(回归 ISS-0012 既有用例)。

## 5. 约束

- 不改急停热键语义(Ctrl+Shift+F11)与 estop-state.json 文件邮箱协议;
- 与 ISS-0002(瘦代理)、ISS-0046(单例守门)既有设计衔接,不另起互斥机制;
- fail-closed:任何仲裁失败 = 显式审计 + 告警,禁止静默;
- 本单只到「建单+测试设计」,实现走 SDD P1→P2→P3。

## 7. 整改设计(评审通过后由 SDD 执行;sdfang 2026-09-15 裁「全做」)

### 7.1 结构

新模块 `deskpilot/ownership.py`:

| 组成 | 职责 |
|------|------|
| `OwnerLock` | `audit/owner.lock` 文件锁(msvcrt.locking 非阻塞,进程退出 OS 自动放锁,无残留);内容 {pid, role, ts};**持锁者 = 属主** |
| `HeartbeatWriter` | 周期(10s)原子写 `audit/daemon-heartbeat.json` {pid, role, ts, version};**daemon 与 stdio 属主同机制**(stdio 侧死亡同样不可见——断连死因即缺此观测,纳入同一机制) |
| `is_daemon_alive()` | 读心跳文件,`ts` 新鲜度 <30s 且 role=="daemon" → daemon 在 |
| 遗嘱 | atexit + sys.excepthook 钩子,尽力落审计「进程退出-原因」(正常/异常/信号) |

### 7.2 属主协议(②+⑥合一)

**谁持锁,谁就是属主;属主开 9420 HTTP + 注册热键 + 挂托盘。**

- daemon 启动:持锁 → 心跳 → 9420 → 热键 → 托盘(既有形态);
- stdio 启动:先试持锁——**拿到**:升属主(心跳 + 9420 + 热键 + 托盘,管理入口随 MCP 存活,⑥);**拿不到**:瘦代理探 9420(既有);
- **daemon 复出回迁**:stdio 属主周期(10s)查 `is_daemon_alive()`——daemon 心跳新鲜则**让位**:注销热键、停托盘、停 HTTP、放锁;daemon 侧持锁重试(1s 起步,2s 上限)直至拿锁后绑 9420;
- **热键争抢节流**(②):注册失败审计只记**首次**与**状态恢复**两条,中间退避重试零刷屏(修复本次观测到的每分钟刷屏);
- 托盘单例:只有属主挂托盘,多实例并存不再多出图标。

### 7.3 死亡告警(③)

任一实例(含瘦代理)的周期循环里查 `is_daemon_alive()`:daemon 心跳文件存在但过期(>30s)→ 记审计「daemon 死亡告警」+ 属主弹一次通知窗(每段死亡期一次,不重复轰炸)。

### 7.4 开机自启(⑤)

daemon 启动时向 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 冪等注册 `DeskPilotDaemon = <exe> --daemon`(已在即不写);记审计「开机自启注册」。测试替身 `winreg`,断言写入内容与冪等,不碰真注册表。

### 7.5 死因排查(④)

非代码项:①落地后重启观察一轮,daemon 死亡若再现,遗嘱+心跳即为证据起点。
