## 1. 实证链(2026-09-28,全部直读)

1. `browser_get_rect("Find a release")` → `[3258,291,3417,311]`(ISS-0116 修复后坐标准确);
2. click(3337,301)→ 搜索框焦点蓝环(截图直读),**点击命中闭环成立**;
3. `type_text("v0.4.4")` → `TYPE_MISMATCH 粘贴读回校验不一致且重试耗尽`;
4. 截图直读:框内 `v0.4.4v0.4.4`——**首贴成功+重试叠贴**,双倍文本;
5. 推断:首贴后读回通道(UIA ValuePattern 于 web EditControl)返回滞后/空值 → 误判不一致 → 重试在未清场的框内再贴 → 二次仍不一致(内容已是双倍≠目标)→ 报残;
6. 环境注记:同窗口按键探测发现系统中文 IME 在线(「x」触发候选窗);另有一发 daemon 调用 30s 超时,期间两发 backspace 疑似落空(疑与卡顿同期,佐证观测)。

## 2. 嫌疑面(机制层,待定位)

- A. **读回竞态**:web EditControl 的 ValuePattern 值刷新滞后于粘贴完成,读回在值未刷新窗口期采样 → 假不一致;
- B. **重试未清场**:重试直接再 ctrl+v(内容追加)而非先 ctrl+a 全选覆盖——重试路径不幂等是确定的设计缺陷,与读回是否竞态无关;
- C. 读回通道对 web EditControl 走了错误的通道级(如 TextPattern 于 Edge 页面框返回整段旁文本)。

## 3. 改法方向(待裁定,不自作主张)

- ① **重试幂等化**:重试前先 ctrl+a 全选再贴(覆盖语义),无论读回竞态与否都不再叠贴——兜底必做;
- ② **读回延迟重采样**:粘贴后短退避(如 200/500ms 两段)再读回,消竞态;
- ③ ①+② 组合。
涉及写路径行为前提,按上报界线属设计级,请 sdfang 裁定。
