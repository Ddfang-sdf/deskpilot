# ISS-0005：冻结提示弹窗视觉粗糙，需按业界通知审美重做外观

| 项 | 内容 |
|----|------|
| 问题单号 | ISS-0005 |
| 标题 | 冻结弹窗现为 Tk 原生灰底方角样式，视觉粗糙：需参考业界 toast/banner 审美重做（圆角卡片、色彩层级、图标、扁平按钮、滑入+淡入复合动画） |
| 严重级 | 低（纯体验类，不影响安全语义；但冻结弹窗是安全机制的人机界面，观感直接决定用户是否愿意看它、信它） |
| 状态 | 已关闭（2026-08-22 验收通过：209 测试全绿；实盘打包版圆角卡片右下角滑入、按钮点击反馈、解冻滑出消失全链路通过） |
| 提出 | 2026-08-21（ISS-0004 实盘验收后，用户肉眼反馈"解冻窗口太丑"） |

## 1. 问题现状

ISS-0004 落地的冻结提示弹窗功能闭环完整（滑入/解冻/稍后提醒/自动消窗），但视觉是
Tk 默认拼装：系统灰底（`SystemButtonFace`）、直角黑边、原生浮雕按钮、纯文本无层级，
整体观感接近 Windows 95 对话框。具体短板：

1. **无色彩语义**：冻结是"危险/警示"事件，现弹窗没有任何色彩传达，与一条普通
   文本消息无差别。
2. **无视觉层级**：标题、触发来源、说明文字、热键提示全靠字号粗细微调，没有
   前景/背景/弱化文的层次区分。
3. **无图标**：业界通知（Windows toast、macOS banner、VS Code、Material banner）
   均以图标承担第一识别，现弹窗零图形元素。
4. **按钮原生样式**：浮雕边框、系统灰，主次不分（"立即解冻"是主操作却与"稍后提醒"
   同样式并排）。
5. **直角生硬**：`overrideredirect` 裸窗，无圆角无阴影无过渡透明度，滑入是唯一
   动效，突兀。

## 2. 根因分析

| # | 根因 | 说明 |
|---|------|------|
| R1 | ISS-0004 范围只覆盖功能闭环 | 当期的验收标准是"弹得出、点得动、消得掉"，视觉未立项，Tk 默认样式直接上了生产。 |
| R2 | Tk 无现成现代组件 | 圆角/阴影/扁平按钮/悬停态在 Tk 里都要手工实现（画布色键抠圆角、`relief="flat"` + 自绘、Enter/Leave 绑悬停），不投入就只能是原生脸。 |

约束（保持 ISS-0004 既定语义不动）：弹窗仍是通知层而非安全闸；状态机、文件邮箱、
seq 守卫、落位（右下角）、热键提示文案全部不变——**本单只改外观，不改行为**。

## 3. 整改方案

### 3.1 设计基调

参考对象：Windows 11 通知中心 toast、VS Code 通知、Material Design banner。
基调：**浅色圆角卡片 + 左侧警示色条 + 图标 + 主次分明的扁平按钮**。
冻结是警示事件但非错误（用户自己也可能主动触发），色取用**琥珀/橙红警示色**
（`#D83B01`，Windows 系 warning 橙），不用纯红避免误读为系统崩溃。

### 3.2 视觉规格（标注稿）

```
 ╭──────────────────────────────────────────╮
 │ ▍🛡  DeskPilot 已冻结                    │  ← 色条4px + 图标 + 标题 13px 半粗 #1F1F1F
 │ ▍   触发：鼠标甩角 · 2026-08-21 09:36     │  ← 次级文本 9px #605E5C
 │ ▍   AI 的写操作已全部拒绝（EMERGENCY_STOP）│  ← 正文 9px #323130
 │ ▍   可按 Ctrl+Shift+F11 直接解冻          │  ← 热键提示弱化 8.5px #8A8886
 │ ▍                                        │
 │ ▍   [ 立即解冻 ]   [ 稍后提醒(180s) ]     │  ← 主按钮实心#D83B01白字 / 次按钮白底灰框
 ╰──────────────────────────────────────────╯
```

| 元素 | 规格 |
|------|------|
| 卡片 | 440×210（尺寸不变），白底 `#FFFFFF`，圆角半径 8px，1px 描边 `#EDEBE9` |
| 警示色条 | 左缘竖条宽 4px，全高，`#D83B01`，随卡片圆角 |
| 图标 | 🛡（Segoe UI Emoji 彩色渲染）；标题行左对齐，图标+标题基线对齐 |
| 标题 | Microsoft YaHei UI 13px bold，`#1F1F1F` |
| 触发来源 | 9px `#605E5C`（次级） |
| 正文 | 9px `#323130` |
| 热键提示 | 8.5px `#8A8886`（弱化） |
| 主按钮"立即解冻" | 实心 `#D83B01` 白字，flat 无框，圆角 4px（自绘或近似），悬停 `#C33401`，按下 `#A82C01` |
| 次按钮"稍后提醒" | 白底 1px 灰框 `#8A8886`，文字 `#323130`，悬停底色 `#F3F2F1` |
| 点击反馈 | 沿用 v0.4 语义：主按钮点击后置灰显示"解冻请求已发送…"，底色降为 `#F3F2F1` 文字 `#8A8886` |
| 背景 | 弹窗外区域全透明（色键抠除），桌面内容透出 |

### 3.3 Tk 实现要点（圆角与透明是唯一难点）

1. **圆角**：`Canvas` 铺满窗口，`root.attributes("-transparentcolor", CHROMA)`
   色键透明（如 `#010101` 铺底），`create_polygon(smooth=True)` 或两段
   `create_arc`+矩形拼圆角卡片。色键透明是 1-bit（无抗锯齿），8px 圆角下
   锯齿不可辨——可接受；不追求 Windows 11 的亚克力模糊（Tk 做不到，不强求）。
2. **阴影**：Tk 无原生阴影。近似方案：色条+描边已够勾勒边界，**不做假阴影**
   （1-bit 透明下半透明阴影画不出来，强行做只会更丑）。实测若边界感不足，
   描边加深至 `#D2D0CE`。
3. **按钮**：`relief="flat"`、`bd=0`、自设 bg/fg/activebackground；
   `bind("<Enter>/<Leave>")` 实现悬停换色；`padx/pady` 撑出尺寸。
   按钮圆角用同样画布技巧代价过高，采用方角扁平（业界 Windows toast 按钮
   即方角扁平，风格自洽）。
4. **图标**：🛡 用 `Segoe UI Emoji` 字体直接渲染彩色字形，不引入图片资源
   （onefile 打包免资源路径问题）。若实测彩 emoji 渲染失败，降级为 ⚠。
5. **动画升级**：滑入/滑出 240ms 对称保留（ISS-0004 对称原则不变），叠加
   **淡入/淡出**：`-alpha` 从 0.0→1.0（滑入）/ 1.0→0.0（滑出）与位移同帧同步，
   同一缓动表驱动，总时长不变。动画纯函数 `slide_in_xs` 扩展为
   `slide_in_frames(screen_w) -> list[(x, alpha)]`，滑出仍为逐帧反向。
6. **DPI**：窗口尺寸/字号/色条宽度全部走 Tk 逻辑像素（Tk 自处理 150% 缩放），
   禁止硬编码物理像素——本次实盘已验证 Tk 几何在 150% DPI 下正确。

### 3.4 改动边界

- 只动 `freeze_dialog.py`：新增样式常量区（颜色/字号表）+ `_paint_card()` 画布
  装配 + 按钮工厂 `_make_button()`；状态机、poll、文件邮箱、按钮回调逻辑零改动。
- 审批弹窗（approval_dialog.py）**不在本单范围**；但样式常量表设计成可拷贝复用
  的纯数据块，后续若审批窗要统一风格，抽公共模块即可（届时另立单）。
- 三份设计说明书同步：详细设计 §11.6 弹窗内容段补视觉规格引用本单；测试设计
  新增 TC-N-EST-13（动画帧含 alpha 序列、滑入滑出对称）与 TC-N-EST-14
  （样式常量完整性：主/次/悬停/禁用四态色值齐全）。

## 4. 测试方案

### 4.1 单元

| 用例 | 断言 |
|------|------|
| 动画帧含透明度 | `slide_in_frames` 返回 (x, alpha) 序列：alpha 首帧 0.0、末帧 1.0、单调不减；滑出=滑入逐帧反向；时长仍 240ms |
| 位移回归 | x 序列与既有 `slide_in_xs` 完全一致（动画升级不改变落位与轨迹） |
| 样式常量完整性 | 主按钮三态（normal/hover/pressed）与禁用态、次按钮两态色值全部定义且互不相同 |

### 4.2 集成验收（实盘，人眼）

- 甩角冻结 → 右下角滑入+淡入圆角卡片：色条/图标/三级文字层级/主次按钮观感符合 §3.2
- 悬停两按钮有换色反馈；点"立即解冻"→ 置灰"解冻请求已发送…"→ 解冻滑出+淡出消失
- 再冻结 → 点"稍后提醒"→ 滑出+淡出隐藏，到点重弹；热键 F11 解冻 → 自动滑出消失
- 150% DPI 下无布局错位、无圆角撕裂、emoji 正常上色（失败则按 §3.3-4 降级 ⚠ 并记录）
