- **常驻 daemon 形态**（ISS-0001）：服务进程常驻，MCP 调用不再每次重启进程，单次调用约 1.2s；绑定跨调用保持
- **急停复位通道**（ISS-0002）：冻结后 `Ctrl+Shift+F11` 或 `deskpilot.exe --reset` 复位；热键注册失败退避重试不静默放弃
- **L3 审批批准即执行**（ISS-0003）：批准后同一调用内同步执行，不再只批不动
- **冻结人类感知**（ISS-0004/0005/0006）：冻结即时弹窗（警示圆角卡片滑入滑出、立即解冻/稍后提醒）、单弹窗不重复开、解冻请求不错序消费
- **性能优化**（ISS-0008）：daemon 线程化、OCR 懒加载、证据图 JPEG、窗口枚举去重、空闲自停；审批挂起期 /health 38~69ms
- **Claude 客户端断链可靠性**（ISS-0009）：进度通知、超时预算、stdout 卫生、版本握手
- **截图受管目录与时空双阈值清理**（ISS-0010）：截图统一落受管目录，按容量/时长双阈值自动清理
- **多显示器（双屏）支持**（ISS-0007）：审批/冻结弹窗跟随目标窗口/鼠标所在屏；截图与 UI 树声明虚拟桌面坐标系（含负坐标）；DPI 感知升级 Per-Monitor V2；急停触发角文档化为主屏左上角
- **发布自动化与安装指导**（ISS-0011）：tag 即发布的 GitHub Actions 流水线、INSTALL.md 安装指导书、install.ps1 一键安装脚本
- **白名单审批入白与全可视化管理**（ISS-0012）：非白名单软件弹窗三态入白（本次会话允许/永久加入/拒绝），永久加入由系统原子写盘；系统托盘图标+白名单管理窗口（搜索/分区/更多/描述）；AI 请求撤回确认窗；策略文件指纹审计；deskpilot.exe 自保护永不可入白
- **弹窗静默修复**（ISS-0013）：弹窗线程默认工厂接线（曾致生产弹窗全哑）；测试设计五条硬规则（装配守门）
- **工具描述意图化**（ISS-0015）：24 个工具意图化描述（用途/场景/参数返回/组合链）+ server 级领域划界指令（Windows 桌面 vs 浏览器路由）
- **窗口定位与读取可靠性**（ISS-0016）：UIA 线程级 COM 惰性初始化，错误分类（UIA 通道异常 vs 窗口消失），搜索无果给进程名指引
- **窗口激活容错与提权边界**（ISS-0017）：激活还原+前台锁退避；写前提权检测（目标以管理员运行显式报错 ELEVATION_REQUIRED）；落点遮挡判定
- **路径与配置一致性**（ISS-0018）：截图返回绝对路径；policy.yml 单源化（构建同步+哈希一致）
- **审批批量授权**（ISS-0019）：「此后同类允许」按钮——同窗口同工具会话内后续同类免批（仅内存令牌；终端与危险键仍逐次审批）
- **审批可读性**（ISS-0020）：主标题直接显示命令文本/坐标；无绑定审批反查实拍；取图失败审计留痕；弹窗图像 GC 空白修复
- **审批截图四步契约**（ISS-0020 续）：找到目标窗口→前置→无遮挡校验→才截图；修入白审批漏传请求致弹框无图；废全屏静默退化，拍不到就明示不给错图
