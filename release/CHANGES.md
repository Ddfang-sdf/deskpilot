## v0.3.5

- **screenshot 感知自愈**（ISS-0037）：响应附 `vision_note` 降级指引（图像不可见时改调 `ocr(source=路径)`，零摸索）；`ocr:true` 一次调用返回图像+文字清单（OCR 失败显式附 `ocr_error`，图像不受损）；严格 bool 参数校验
- **OCR 超时指引与预算覆盖**（ISS-0039）：ocr/screenshot 专属时限预算 12s（实测全屏 CPU 推理首推 5.2s 超旧 5s 预算，负载下必然超时）；ocr 描述明示「局部实拍优先+超时按指引重试」
- **工具清单构建修复**（ISS-0040【修改引入】）：inputSchema 类型映射补齐 bool，修复 list_tools 全量 KeyError 致 MCP 客户端「tools fetch failed」
- **README 加白管理能力**：入白审批与白名单管理实拍截图、双文件政策（policy.yml 基础 / policy.local.yml 用户数据，升级不丢、移出即墓碑）
- **需求演进体系**：docs/需求/ 建立 REQ-001 鼠标能力补全 / REQ-002 桌面图标感知（原始输入随单归档）
- 测试：536 用例全绿（默认零副作用）

## v0.3.4

- **按文字点击 click_text**（ISS-0021）：OCR 定位文字→自动换算虚拟桌面坐标→与裸坐标点击同安全链（防误射/遮挡校验/证据图）；未命中/多命中 fail-closed；多命中必须显式 index；screenshot 返回坐标系元数据（virtual_rect/scale）
- **按键可发现**（ISS-0022）：未收录键错误返回完整可用键清单并明示「本次未发送任何按键」；浏览器标签/窗口组合键（ctrl+t/n/l/tab/r）收 L3 本地审批
- **TOOL_TIMEOUT 重试指引**（ISS-0023）：超时响应带 retry_after_ms 与建议次数，AI 可自愈重试
- **审批超时链修复**（ISS-0024/0033）：90 秒审批期内调用不再中途报超时（此前 30 秒即断线，「报错但动作可能已执行」）；客户端超时改由策略推导，消除魔法常量
- **AI 可自愈错误规范**（ISS-0027）：参数类错误回显服务端实收值；OCR 未命中附相似文本建议（仅建议、无载荷、不自动执行）
- **测试卫生**（ISS-0025/0026/0029）：默认 pytest 零副作用（不开真实窗口、不读生产目录），真机集成需 `--run-integration`；用例独立（随机序 CI 防护）；删除死代码登记册
- **甩角阈值 200→1000ms**（ISS-0028）：消除鼠标路过角落的误冻结
- **出厂策略与用户数据双文件分离**（ISS-0030/0032）：永久入白写入 `policy.local.yml`，升级/重装自动保留（`--migrate-policy` 迁移）；撤回记录永续（墓碑）；用户数据文件无权放宽任何安全参数
- **审计数据保留策略**（ISS-0031）：日志保留 90 天；截图 90 天+450MB 双阈值（合计 ≤500MB，容量为硬顶）
- **守护机制修正**（ISS-0034）：服务自身入白写入不再误报外部篡改；策略同步校验接入 CI（漂移即红）
- **文字通道修正**（ISS-0035）：type_text 读回轮询确认，消除滞后重贴导致的文档内容重复；点击/建议共用大小写不敏感归一化
- 测试：515 用例全绿（默认零副作用）

## v0.3.3 及更早

- **常驻 daemon 形态**（ISS-0001）：服务进程常驻，MCP 调用不再每次重启进程，单次调用约 1.2s；绑定跨调用保持
- **急停复位通道**（ISS-0002）：冻结后 `Ctrl+Shift+F11` 或 `deskpilot.exe --reset` 复位；热键注册失败退避重试不静默放弃
- **L3 审批批准即执行**（ISS-0003）：批准后同一调用内同步执行，不再只批不动
- **冻结人类感知**（ISS-0004/0005/0006）：冻结即时弹窗（警示圆角卡片滑入滑出、立即解冻/稍后提醒）、单弹窗不重复开、解冻请求不错序消费
- **性能优化**（ISS-0008）：daemon 线程化、OCR 懒加载、证据图 JPEG、窗口枚举去重、空闲自停；审批挂起期 /health 38~69ms
- **Claude 客户端断链可靠性**（ISS-0009）：进度通知、超时预算、stdout 卫生、版本握手
- **截图受管目录与时空双阈值清理**（ISS-0010）：截图统一落受管目录，按容量/时长双阈值自动清理
- **多显示器（双屏）支持**（ISS-0007）：审批/冻结弹窗跟随目标窗口/鼠标所在屏；截图与 UI 树声明虚拟桌面坐标系（含负坐标）；DPI 感知升级 Per-Monitor V2；急停触发角文档化为主屏左上角
- **发布自动化与安装指导**（ISS-0011）：tag 即发布的 GitHub Actions 流水线、INSTALL.md 安装指导书、install.ps1 一键安装脚本
- **白名单审批入白与全可视化管理**（ISS-0012）：非白名单软件弹窗三态入白（本次会话允许/永久加入/拒绝），永久加入由系统原子写盘；系统托盘图标+白名单管理窗口（搜索/分区/更多/描述）；AI 请求撤回确认窗；策略文件指纹审计；deskpilot.exe 自保护永不可入白
- **弹窗静默修复**（ISS-0013）：弹窗线程默认工厂接线（曾致生产弹窗全哑）；测试设计五条硬规则（装配守门）
- **工具描述意图化**（ISS-0015）：24 个工具意图化描述（用途/场景/参数返回/组合链）+ server 级领域划界指令（Windows 桌面 vs 浏览器路由）
- **窗口定位与读取可靠性**（ISS-0016）：UIA 线程级 COM 惰性初始化，错误分类（UIA 通道异常 vs 窗口消失），搜索无果给进程名指引
- **窗口激活容错与提权边界**（ISS-0017）：激活还原+前台锁退避；写前提权检测（目标以管理员运行显式报错 ELEVATION_REQUIRED）；落点遮挡判定
- **路径与配置一致性**（ISS-0018）：截图返回绝对路径；policy.yml 单源化（构建同步+哈希一致）
- **审批批量授权**（ISS-0019）：「此后同类允许」按钮——同窗口同工具会话内后续同类免批（仅内存令牌；终端与危险键仍逐次审批）
- **审批可读性**（ISS-0020）：主标题直接显示命令文本/坐标；无绑定审批反查实拍；取图失败审计留痕；弹窗图像 GC 空白修复
- **审批截图四步契约**（ISS-0020 续）：找到目标窗口→前置→无遮挡校验→才截图；修入白审批漏传请求致弹框无图；废全屏静默退化，拍不到就明示不给错图
- 测试：434 用例全绿
